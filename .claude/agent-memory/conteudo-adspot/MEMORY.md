## Aprendizados

- 2026-09-23 · O painel HTML é só viewer + planejador local (localStorage); quem escreve o conteúdo de verdade sou eu, no chat · uma página estática publicada não tem como chamar o modelo sozinha · como aplicar: todo botão "🪄" do painel só monta e copia o comando — sempre que o Vitor colar um desses comandos aqui, tratar como o pedido correspondente da metodologia (seção 5 para semana, 7 para ideias etc.) e, ao terminar, rodar `gerar_conteudo_html.py` e avisar que o painel foi atualizado.
- 2026-09-23 · Cliente cadastrado só na tela (painel) não existe pra mim até o Vitor colar o JSON ou pedir o cadastro por aqui · o painel guarda isso só no navegador dele · como aplicar: se o Vitor falar de um cliente que não tem `clientes/adspot/conteudo/<slug>/cliente.json`, perguntar se é pra cadastrar agora.
